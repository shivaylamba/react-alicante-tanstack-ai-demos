## Design Context
### Users
Shivay presenting to a large React conference. Audience must understand the transformation from far away. Laptop and phone rehearsal.
### Brand Personality
Playful, theatrical, candid. Playful fictional Alicante beach-shop demos with inspectable real APIs.
### Aesthetic Direction
A printed show programme meets a launch control desk. Warm cream stage, ink type, vermilion accents. Large expressive headings, a distinct visual for each act, no generic dashboard cards. Fonts: Bricolage Grotesque and Public Sans. No heavy 3D runtime.
### Design Principles
1. Each demo changes a big visible object, not merely chat text.
2. Expose one small working API example on demand.
3. Honest live/rehearsal labels and visible errors; never silently fake a provider.
4. Keyboard-friendly numbered acts, reset, stop, and large controls.
5. Respect reduced motion and keep one server and one test worker.

### Interactive presentation update
Reference: Rudraksh Karpe’s OpenVoice presentation. Use its manual reveals, hash chapters, notes, source panel and clear fullscreen navigation as interaction inspiration. The exact supplied React Alicante title image opens a 41-slide presentation. Introductions, eight feature-demo-code sequences, recaps and a workshop QR share one shell. No Ship Happens branding, countdown or duration stamps. Code is syntax-highlighted and explained in three focused blocks with full source available. Preserve completed demo state, cancel unseen active requests, and never trigger paid model calls through slide navigation. Keep the original cream, ink and vermilion identity, with a dark theme and reduced-motion option.
